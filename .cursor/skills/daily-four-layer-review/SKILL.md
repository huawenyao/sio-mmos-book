# 四层每日复盘

## 流程

1. **静态层**：测边界、测支撑、测安全度 → 可召唤 `/stasis-cartographer`
2. **增量层**：找五要素边际变化量 → `/flow-tracker`
3. **虚实层**：预期落地？透支？ → `/consensus-observer`
4. **反馈层**：趋势延续还是势能衰竭？ → `/feedback-diagnostician`
5. **免疫**：`/axiom-immune` 快速审查
6. **输出**：当日操作含义（持有/加减仓/观望）+ 明日监控三条

...

...

1. ...
