# 二元分析清单

读取 `axiom-alpha/knowledge/analysis-model/static-dynamic-fusion.md` 后，按清单逐项输出。

## 静态（必填）

1. 上下边界在哪里？
2. 支撑底层条件（成本/产能/需求/政策）？
3. 什么变化量能破坏支撑？

## 动态（必填）

1. 资金边际方向与强度？
2. 靠近边界时量能萎缩还是放大？
3. 是否形成正/负自反馈？

## 虚实（必填）

1. 预期 vs 落地增量是否匹配？
2. 透支还是不足？
3. 叙事是否有基本面支撑改善？

## 判定

对照决策矩阵给出：试仓 / 加仓持有 / 回避减仓，并引用 A1–A5 与对应定理。

可召唤：`/stasis-cartographer`、`/flow-tracker`、`/consensus-observer`。
