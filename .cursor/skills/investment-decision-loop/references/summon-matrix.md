# 动态召唤矩阵

## 公理维度 → 专家

| axiom_dimension | 主召唤 | 可选协同 |
|-----------------|--------|---------|
| stasis_field | stasis-cartographer | — |
| potential_topology | stasis-cartographer | flow-tracker（验证冲击能量） |
| flow_dynamics | flow-tracker | feedback-diagnostician |
| consensus_state | consensus-observer | dialectic-engine（若 ERG 极端） |
| loop_competition | feedback-diagnostician | flow-tracker |
| cross_axiom | epistemic-runner 编排多专家并行 | dialectic-engine |

## 协作模式

| 模式 | 何时 | 如何 |
|------|------|------|
| 串行 | 存在硬依赖 | 先基线（stasis）再变化（flow） |
| 并行 | 独立维度 | stasis ∥ flow ∥ consensus 同时启动 |
| 辩论 | 免疫 FORCE_DIALECTIC 或证据对撞 | dialectic-engine |

## 激活深度

| 级别 | 含义 |
|------|------|
| scan | 核心指标快扫 |
| standard | 核心+辅助 |
| deep | 全面下钻+交叉验证 |

由 `intent.required_depth` 与 `question.estimated_depth` 共同决定。
