# 定理模式识别模板

> 定理不是 if-then 规则，而是 LLM 的模式识别模板。

| ID | 模式 | 模板描述 |
|----|------|---------|
| oscillation | 震荡 | 存量稳固 + 增量不足 → 系统被困在势阱中做布朗运动 |
| trend_emergence | 趋势涌现 | 持续同向流 + 边界击穿 → 系统跃迁到新吸引子盆地 |
| inflection_exhaustion | 拐点衰竭 | 增量加速度归零 → 增量见顶 → 存量拐点 → 价格拐点 |
| phase_transition | 相变 | 临界慢化 + 控制参量穿越阈值 → 系统行为质变 |
| consensus_collapse | 共识崩塌 | 共识过饱和 + 边际参与者耗尽 → 信念突然相变 |
| virtual_over_real | 虚大于实 | 预期透支 + 实增量不足 → 见顶风险（定理5） |
| virtual_real_resonance | 虚实共振 | 预期与持续增量同向 → 真主线（定理6） |
| boundary_reversion | 边界回归 | 价格远离有效边界 → 回归引力增大（定理4） |
| entropy_decrease | 熵减 | 五要素同向共振 → 有序趋势（定理9） |
| entropy_increase | 熵增 | 五要素散乱背离 → 无序震荡（定理9） |
