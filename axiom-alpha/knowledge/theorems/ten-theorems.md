# 十大核心定理（由公理严格推导）

| 定理 | 推导来源 | 陈述摘要 | 应用 |
|------|---------|---------|------|
| T1 震荡定理 | A1+A2 | 存量稳定+无持续增量 → 必然震荡回归 | 高抛低吸，不追涨杀跌 |
| T2 趋势定理 | A2+A3 | 持续同向增量累积 → 突破边界 → 新稳态 | 趋势持有，直至增量衰竭 |
| T3 拐点定理 | A2+A5 | 边际增量由强转弱/虚实背离 = 唯一拐点 | 监测增量斜率，衰竭即离场 |
| T4 边界回归定理 | A1+A3 | 偏离边界越远，回归引力越大 | 远离警惕回归，靠近找支撑 |
| T5 虚实验证定理 | A4+A2 | 虚>实见顶；虚<实主升；匹配延续 | 背离减仓，匹配持有 |
| T6 题材生命周期 | A4+A2+A5 | 纯虚一日游；有实无续短波；虚实共振主线 | 只参与虚实持续共振 |
| T7 周期嵌套定理 | A1+A2+A3 | 大周期约束小周期；小增量可重塑大边界 | 大趋势向上短跌是回调 |
| T8 资金流迁徙 | A1+A2 | 存量=跷跷板；增量=全线抬升 | 存量高低切换，增量重仓主线 |
| T9 熵增熵减定理 | A2+A5 | 五要素同向=熵减趋势；散乱=熵增震荡 | 熵减重仓，熵增空仓 |
| T10 强弱不可逆 | A1+A3 | 存量重塑后新边界短期内不可逆 | 趋势确认后持有，不逆势 |

---

## 定理详述

### 定理1【震荡定理】
存量结构稳定 + 无持续增量 → 市场必然震荡、回归边界。  
80% 的 A 股常态行情都是震荡。

### 定理2【趋势定理】
持续同向关键变化量累积 → 突破边界 → 新稳态形成 → 趋势延续。

### 定理3【拐点定理】
趋势延续的唯一终结条件：**边际增量由强转弱、由正转负、虚实背离**。势能衰竭 = 唯一拐点。

### 定理4【边界回归定理】
价格脱离基本面/筹码边界越远，回归引力越大。所有泡沫、崩盘服从此定理。

### 定理5【虚实验证定理】
- 虚预期大于实增量 → 见顶
- 虚预期小于实增量 → 主升
- 虚实匹配 → 趋势延续

### 定理6【题材生命周期定理】
- 纯虚无实：一日游
- 有实无续：短波段
- 虚实持续共振：真主线大行情

### 定理7【周期嵌套定理】
大周期存量边界约束小周期运动；小周期持续增量突破重塑大周期边界。

### 定理8【资金流迁徙定理】
- 存量资金市场：板块跷跷板
- 增量资金市场：全线抬升

### 定理9【熵增熵减定理】
- 五要素同向共振 = 熵减 = 有序趋势
- 五要素散乱背离 = 熵增 = 无序震荡

### 定理10【强弱不可逆定理】
存量结构重塑后的新边界，短期内不可逆。趋势成型后惯性极强。
