# 系统模型｜静态边界-动态博弈融合分析框架

> **定位**：分析模型层 · 将公理转化为可直接使用的思维框架与操作清单

---

## 一、静态结构：边界点与支撑结构

### 价值边界（基本面边界）
- 企业/行业盈亏平衡线、产能成本线、供需均衡价格中枢
- 长期估值上下限、产能出清临界阈值

### 筹码边界（交易边界）
- 历史筹码密集区、机构底仓成本中枢、板块拥挤度极值

### 支撑结构（地基）
产能壁垒、资源约束、成本曲线、长期需求基线、政策底线、行业进入门槛

> **关键洞察**：没有支撑结构的边界是"虚边界"，很容易一次性击穿。

### 基本面分析新定义
测绘市场静态存量结构，识别有效边界点，验证支撑结构牢固程度，划分震荡天然区间。

回答三个问题：
1. **向下**：跌到哪里有实质性产业买盘支撑？
2. **向上**：供需不变时，长期天花板在哪里？
3. **支撑结构是否稳固？** 什么条件会让边界失效？

---

## 二、动态系统：能量观测信号

| 信号 | 含义 |
|------|------|
| 缩量 | 内部博弈衰减，靠近边界易回归 |
| 持续放量 | 新旧力量激烈博弈，可能击穿边界 |
| 持续边际资金流入 | 正向能量累积，冲击上边界 |
| 持续边际资金流出 | 负向能量累积，测试下边界 |

### 技术分析新定义
观测动态系统内部的能量流动与自反馈强弱，跟踪价格靠近边界时博弈力量是遇边界回归，还是蓄力突破。

---

## 三、闭环融合链路

```
基本面测绘【静态】→ 锁定上下边界 + 支撑强度
        ↓
技术/资金观测【动态】→ 跟踪量能、资金边际、势能、自反馈
        ↓
虚实闭环校验【潜空间】→ 预期是否落地/透支
        ↓
结局A：能量不足 → 边界生效 → 震荡回归
结局B：持续同向增量 → 击穿边界 → 趋势行情
```

---

## 四、二元分析清单

### 静态（基本面）
1. 当前上下边界在哪里？
2. 支撑边界的底层条件是什么？
3. 什么关键变化量能破坏支撑结构？

### 动态（资金/量价）
1. 资金边际变化方向与能量强度？
2. 靠近边界时量能萎缩还是放大？
3. 是否形成正向/负向自反馈？

### 虚实闭环
1. 市场预期（虚）与已落地增量（实）是否匹配？
2. 预期透支还是不足？
3. 远期业务叙事是否有基本面支撑改善？

### 最终决策判定

| 场景 | 判定 | 操作 |
|------|------|------|
| 边界稳固 + 动态能量抵达临界即将反转 | 高价值机会 | 试仓买入 |
| 支撑结构改变 + 持续资金增量具备突破条件 | 趋势机会 | 加仓持有 |
| 纯资金炒作，静态边界无改善，行情脱离合理区间 | 高风险 | 回避/减仓 |

---

## 五、四层每日复盘标准

1. **静态层**：测边界、测支撑、测安全度
2. **增量层**：找五要素边际变化量
3. **虚实层**：验证预期是否落地、是否透支
4. **反馈层**：判断趋势是否延续、势能是否衰竭
